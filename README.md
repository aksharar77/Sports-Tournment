# Sports-Tournment
A simple Python project that allows users to input the scores of two competing teams and determines whether the match resulted in a **win**, **loss**, or **tie** for the user’s team.

## 📌 Features

- Input team names and their respective scores
- Compares scores and determines:
  - ✅ Win
  - ❌ Loss
  - 🤝 Tie
- Displays a clear match summary

## 🚀 How It Works

1. The user is prompted to enter:
   - Their own team name
   - Opponent team name
   - Score of their team
   - Score of the opponent team

2. The program compares both scores:
   - If both scores are equal ➝ **Match Tied**
   - If the user's team has a higher score ➝ **User’s Team Wins**
   - If the user's team has a lower score ➝ **User’s Team Loses**

3. A final summary is printed, showing:
   - Both team names
   - Their scores
   - Match result
